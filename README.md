# Call Center Customer Service Dashboard

## Overview
This project involves the creation of an interactive **Call Center Customer Service Dashboard** using **Power BI** and **Power Query (Excel)**. The dashboard provides insights into call center performance, including call volume, response times, customer satisfaction, and regional analysis. The goal is to identify inefficiencies, improve customer service, and optimize resource allocation.

## Key Features
- **Interactive Filters:** Users can filter data by city, region, and time period.
- **Key Metrics:** Displays total calls received, average call duration, average CSAT score, and SLA compliance.
- **Call Analysis:** Tracks late deliveries, on-time responses, and canceled calls.
- **Regional Insights:** Visualizes call volume and response times by region.
- **Time-Based Trends:** Shows call volume trends by weekdays and months.

## Dataset
The dataset used for this project includes information on:
- Calls (e.g., call ID, duration, status)
- Customers (e.g., location, satisfaction score)
- Regions (e.g., city, state)
- SLA (Service Level Agreement) metrics

## Tools and Technologies
- **Power Query (Excel):** For data cleaning, transformation, and preparation.
- **Power BI:** For data visualization and dashboard creation.
- **DAX (Data Analysis Expressions):** For creating calculated metrics (e.g., Average CSAT Score, SLA Compliance).

## Questions Answered
This project addresses the following key business questions:
1. **What is the total call volume and average call duration?**
   - The dashboard shows **30,165 calls** were received, with an average call duration of **25.03 minutes**.

2. **Which regions have the highest call volumes and response times?**
   - **Los Angeles/CA** and **New York City** had the highest call volumes, while **Chicago/IL** had the lowest SLA compliance (55%).

3. **What is the average customer satisfaction (CSAT) score?**
   - The average CSAT score is **4.72**, indicating room for improvement in certain regions.

4. **How does call volume vary by weekdays and channels?**
   - Call volume peaked on **Mondays**, and the **Call Center** channel handled the majority of calls (9.7K).

5. **What percentage of calls met the SLA compliance?**
   - **62.60%** of calls met the SLA, while **34.2%** were below the target response time.

## Key Insights
1. **Call Volume Trends:** Call volume peaked on **Mondays**, indicating a need for additional staffing at the start of the week.
2. **SLA Compliance:** Only **62.60%** of calls met the SLA, with the lowest compliance in **Chicago/IL** (55%).
3. **Customer Satisfaction:** The average CSAT score was **4.72**, with the lowest scores in regions with high call volumes (e.g., Los Angeles).

1. **Download the Dashboard:**
